    1. Create `src/topology/topologyReducer.ts`:

       ```typescript
       import { hierarchy, tree } from 'd3-hierarchy';
       import type { AgentEvent } from '../types/agent';
       import type { TopologyNode, TopologyEdge, TopologyState } from '../types/topology';
       ```

       Implement `buildTopology(events: AgentEvent[], workspaceFilter?: string): TopologyState`:

       **Step A — Build node map from events:**
       - Iterate events in timestamp order
       - `SessionStart` -> create root node: `{ sessionId: event.sessionId, parentSessionId: null, workspaceId: event.workspaceId, agentRole: event.raw?.agentRole ?? null, model: event.model ?? null, status: 'running', opacity: 1.0, x: 0, y: 0, startedAt: event.timestamp, stoppedAt: null }`
       - `SubagentStart` -> create child node: `{ sessionId: event.sessionId, parentSessionId: resolveParentSessionId(event, nodeMap), ... status: 'running', opacity: 1.0 }`. The `parentSessionId` is resolved by finding the node whose session owns `event.parentToolUseId` (for now, use the most recently created running node in the same workspace as the parent if parentToolUseId is not available — fallback logic)
       - `SubagentStop` -> find node by sessionId, set `status: 'stopped'`, `opacity: 0.5`, `stoppedAt: event.timestamp`
       - `SessionEnd` / `Stop` -> find root node by sessionId, set it and all descendants to `status: 'stopped'`, `opacity: 0.5`
       - Skip events where the sessionId is already in the node map for Start events (dedup)
       - If `workspaceFilter` is provided, only include nodes where `workspaceId === workspaceFilter`

       **Step B — Build edges from parent-child relationships:**
       - For each node with a `parentSessionId`, create edge: `{ id: '${parentSessionId}->${sessionId}', sourceSessionId: parentSessionId, targetSessionId: sessionId, isActive: node.status === 'running', status: node.status }`

       **Step C — Compute layout with d3-hierarchy:**
       - Group nodes by root (nodes with `parentSessionId === null`)
       - For each root, build `d3.hierarchy()` tree from the parent-child relationships
       - Apply `d3.tree().nodeSize([160, 80])` (160px horizontal, 80px vertical per D-05 and UI-SPEC)
       - Map computed `{ x, y }` back onto TopologyNode objects
       - For multiple roots (multiple sessions), offset each root tree horizontally by the previous tree's width + 200px gap

       **Step D — Return `{ nodes, edges }`**
