<threat_model>
## Security Considerations

1. **sql.js WASM loading:** Use `locateFile` to point to extension's dist/ directory explicitly. Never load WASM from untrusted paths.
2. **SQLite atomic flush:** Write to temp file + rename to prevent corruption. Same pattern as settings.json.
3. **PID validation before SIGTERM (CTRL-03):** Before sending `process.kill(pid, 'SIGTERM')`, verify PID is still alive via `process.kill(pid, 0)`. Wrap in try/catch. Never send signals to PID 0 or negative PIDs.
4. **Input validation:** AgentEventStore validates required fields before insert. AgentControlManager validates sessionId exists before state transitions.
</threat_model>

Class `AgentEventStore`:
- Constructor: takes `storageUri: { fsPath: string }` and optional `extensionPath: string`. Sets `this.dbPath = path.join(storageUri.fsPath, 'agent-events.sqlite')`.
- `async init(extensionPath?: string)`: Call `initSqlJs({ locateFile: (file: string) => path.join(extensionPath || '', 'dist', file) })` (if extensionPath provided) or `initSqlJs()` (for tests). If `this.dbPath` file exists, load it with `new SQL.Database(fs.readFileSync(this.dbPath))`. Otherwise `new SQL.Database()`. Call `this.createSchema()`.
- `private createSchema()`: Run SQL:
  ```sql
  CREATE TABLE IF NOT EXISTS agent_events (
    id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL,
    session_id TEXT NOT NULL,
    agent_id TEXT NOT NULL,
    event_type TEXT NOT NULL,
    timestamp INTEGER NOT NULL,
    tool_name TEXT,
    tool_input TEXT,
    model TEXT,
    input_tokens INTEGER,
    output_tokens INTEGER,
    cache_read_tokens INTEGER,
    error TEXT,
    raw TEXT NOT NULL
  );
  CREATE INDEX IF NOT EXISTS idx_session ON agent_events(session_id);
  CREATE INDEX IF NOT EXISTS idx_workspace ON agent_events(workspace_id);
  CREATE INDEX IF NOT EXISTS idx_timestamp ON agent_events(timestamp DESC);
  ```
- `insertEvent(event: AgentEvent)`: Parameterized INSERT with all fields. `tool_input` and `raw` serialized as `JSON.stringify()`.
- `getEventsBySession(sessionId: string, limit = 10): AgentEvent[]`: SELECT with ORDER BY timestamp DESC LIMIT. Deserialize `tool_input` and `raw` from JSON.
- `getEventsByWorkspace(workspaceId: string, limit = 50): AgentEvent[]`: Same pattern.
- `getSessionSummary(sessionId: string)`: Returns `{ totalEvents: number, toolUses: number, errors: number, totalInputTokens: number, totalOutputTokens: number, totalCacheReadTokens: number }` via aggregate query.
- `getWorkspaceSummary(workspaceId: string)`: Returns similar aggregation across all sessions for workspace.
- `flush()`: `const data = this.db.export(); const buffer = Buffer.from(data); fs.writeFileSync(this.dbPath + '.tmp', buffer); fs.renameSync(this.dbPath + '.tmp', this.dbPath);`
- `dispose()`: `this.flush(); this.db.close();`

```typescript
import * as vscode from 'vscode';
import type { AgentSession, AgentControlState, AgentEvent } from '../types/agent';
```

Class `AgentControlManager` implements `vscode.Disposable`:
- Private `sessions = new Map<string, AgentSession>()`
- Private `_onDidChangeSession = new vscode.EventEmitter<AgentSession>()`
- Public `onDidChangeSession = this._onDidChangeSession.event`

Methods:
- `registerSession(sessionId: string, workspaceId: string, model?: string)`: Creates `AgentSession` with `controlState: 'running'`, `startedAt: Date.now()`. Stores in map. Fires event.
- `unregisterSession(sessionId: string)`: Removes from map. Fires event with `controlState: 'stopped'`.
- `pauseAgent(sessionId: string)`: Get session, set `controlState = 'paused'`, `pausedAt = Date.now()`. Fire event. Throw if session not found or already paused.
- `resumeAgent(sessionId: string)`: Get session, set `controlState = 'running'`, clear `pausedAt`. Fire event. Throw if not paused.
- `stopAgent(sessionId: string)`: Get session. If `pid` is set and > 0:
  ```typescript
  try {
    process.kill(session.pid!, 0); // check alive
    process.kill(session.pid!, 'SIGTERM');
  } catch { /* process already dead */ }
  ```
  Set `controlState = 'stopping'`. Fire event.
- `isPaused(sessionId: string): boolean`: Return `this.sessions.get(sessionId)?.controlState === 'paused'`
- `getSession(sessionId: string)`: Return from map.
- `getAllSessions(): AgentSession[]`: Return `Array.from(this.sessions.values())`
- `getSessionsForWorkspace(workspaceId: string): AgentSession[]`: Filter by workspaceId.
- `updateSessionPid(sessionId: string, pid: number)`: Set PID on existing session.
- `dispose()`: Clear map, dispose emitter.

Class `NotificationService` implements `vscode.Disposable`:
- Constructor takes `registry: IWorkspaceRegistry`
- `handleEvent(event: AgentEvent)`: Switch on `event.eventType`:
  - `PostToolUseFailure` or `StopFailure`: Call `vscode.window.showErrorMessage('HarnessTune: Agent "${event.agentId}" error — ${event.error || "Unknown error"}', 'View Details')`. On 'View Details' action: `vscode.commands.executeCommand('harnesstune.showDashboard')`. Also increment workspace errorCount: `this.registry.update(event.workspaceId, { errorCount: currentCount + 1 })` — get current via `registry.getById()`.
  - `SessionStart`: Update workspace status to 'running' and increment runningAgentCount via `registry.update()`. No toast.
  - `SessionEnd` or `Stop`: Decrement runningAgentCount. Set status to 'idle' if no running agents remain. No toast.
  - All other events: No notification, no status bar update.
- `dispose()`: No-op (no subscriptions to clean up).
