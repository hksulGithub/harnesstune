<threat_model>
## Security Considerations

1. **CSP in WebviewPanel:** Set Content-Security-Policy meta tag with `default-src 'none'; script-src 'nonce-${nonce}'; style-src ${webview.cspSource} 'unsafe-inline';` — same pattern as sidebar.
2. **acquireVsCodeApi() once:** Call once in module scope `vscodeApi.ts`. Never call again. Second call throws.
3. **No external resources:** localResourceRoots limited to `[extensionUri/dist]`. No CDN, no external scripts.
4. **postMessage validation:** DashboardPanel validates incoming WebviewToHostMessage type field before dispatching to controls.
</threat_model>

```typescript
import * as vscode from 'vscode';
import * as crypto from 'crypto';
import type { HostToWebviewMessage, WebviewToHostMessage } from '../types/messages';
```

Class `DashboardPanel`:
- `public static readonly viewType = 'harnesstune.dashboard';`
- `public static currentPanel: DashboardPanel | undefined;` — MUST be public static so Plan 04's extension.ts wiring can check `DashboardPanel.currentPanel` to push events to the dashboard when open. Do NOT make this private.
- Private `panel: vscode.WebviewPanel`, `extensionUri: vscode.Uri`, `disposables: vscode.Disposable[]`
- Private `_onDidReceiveMessage = new vscode.EventEmitter<WebviewToHostMessage>()`
- Public `onDidReceiveMessage = this._onDidReceiveMessage.event`

Static `createOrShow(extensionUri: vscode.Uri)`:
1. If `currentPanel` exists, reveal it and return it.
2. Create panel: `vscode.window.createWebviewPanel(DashboardPanel.viewType, 'HarnessTune Dashboard', vscode.ViewColumn.One, { enableScripts: true, localResourceRoots: [vscode.Uri.joinPath(extensionUri, 'dist')], retainContextWhenHidden: false })`
3. Construct new `DashboardPanel(panel, extensionUri)`
4. Return instance

Static `revive(panel: vscode.WebviewPanel, extensionUri: vscode.Uri)`:
- Set `currentPanel = new DashboardPanel(panel, extensionUri)`

Private constructor:
1. Store panel and extensionUri
2. Set `panel.webview.html = this.getHtmlForWebview(panel.webview)`
3. Listen for `panel.onDidDispose(() => { DashboardPanel.currentPanel = undefined; dispose disposables })`
4. Listen for `panel.webview.onDidReceiveMessage((msg: WebviewToHostMessage) => { this._onDidReceiveMessage.fire(msg); })`

Public `postMessage(message: HostToWebviewMessage)`: `this.panel.webview.postMessage(message)`
Public `reveal()`: `this.panel.reveal()`

Private `getHtmlForWebview(webview: vscode.Webview): string`:
- Generate nonce via `crypto.randomBytes(16).toString('hex')`
- Get dashboard script URI: `webview.asWebviewUri(vscode.Uri.joinPath(this.extensionUri, 'dist', 'webview', 'dashboard.js'))`
- Return HTML with CSP identical to SidebarViewProvider pattern:
  ```html
  <!DOCTYPE html>
  <html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="Content-Security-Policy" content="default-src 'none'; script-src 'nonce-${nonce}'; style-src ${webview.cspSource} 'unsafe-inline';">
    <title>HarnessTune Dashboard</title>
  </head>
  <body>
    <div id="root"></div>
    <script nonce="${nonce}" src="${scriptUri}"></script>
  </body>
  </html>
  ```

Public `dispose()`: dispose all disposables, set currentPanel to undefined.
