# Phase 02 — UI Design Contract

> Visual and interaction contract for the dashboard WebviewPanel. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — plain React + VSCode CSS variables (D-15) |
| Icon library | VSCode Codicons (built-in, via `@vscode/codicons` CSS classes in webview) |
| Font | `var(--vscode-font-family)` (inherits user's editor font) |

**Rationale:** VSCode extensions must look native. All colors, fonts, and base sizes come from VSCode CSS custom properties. This ensures automatic light/dark/high-contrast theme support.

---

## Spacing Scale

Declared values (multiples of 4, aligned with existing sidebar.css):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding, inline spacing |
| sm | 8px | Compact element spacing, agent card gaps |
| md | 12px | List item padding (horizontal), tab padding |
| lg | 16px | Section padding, card padding |
| xl | 20px | Panel gaps, summary bar padding |
| 2xl | 24px | Major section padding |
| 3xl | 32px | Empty state vertical padding |

Exceptions:
- Workspace tab bar height: 35px (matches VSCode editor tab height)
- Agent card control button touch target: 22px min (codicon button standard)
- Summary bar height: 28px (compact metric strip)

---

## Typography

All sizes use `var(--vscode-font-family)`. Values in px are absolute — VSCode webviews do not inherit the editor font-size setting, so we set explicitly.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 13px | 400 (normal) | 1.4 | Agent detail text, card descriptions, action log entries |
| Label | 11px | 400 (normal) | 1.3 | Secondary text, file paths, timestamps, badge text |
| Heading | 13px | 600 (semibold) | 1.4 | Card titles, section headers, tab labels |
| Metric | 18px | 600 (semibold) | 1.2 | Summary bar numeric values (agent count, error count) |

**Source:** Existing sidebar.css uses 13px body / 11px secondary. Dashboard continues this pattern.

---

## Color

All colors reference VSCode CSS variables for automatic theme support. No hardcoded hex values.

| Role | Variable | Usage |
|------|----------|-------|
| Dominant (60%) | `var(--vscode-editor-background)` | Dashboard panel background |
| Secondary (30%) | `var(--vscode-sideBar-background)` | Agent cards, summary bar, tab bar background |
| Accent (10%) | `var(--vscode-button-background)` | Primary action buttons only: "Connect Workspace", "Resume Agent" |
| Destructive | `var(--vscode-errorForeground)` | Stop Agent button, error badges, error toast icon |

### Semantic Colors (state indicators)

| State | Variable | Elements |
|-------|----------|----------|
| Running | `var(--vscode-terminal-ansiGreen)` | Running status dot, running badge |
| Paused | `var(--vscode-terminal-ansiYellow)` | Paused status dot, paused badge |
| Stopped | `var(--vscode-descriptionForeground)` | Stopped status dot (dimmed) |
| Error | `var(--vscode-errorForeground)` | Error badge, error count in summary |
| Active tab | `var(--vscode-tab-activeBackground)` | Selected workspace tab |
| Inactive tab | `var(--vscode-tab-inactiveBackground)` | Unselected workspace tabs |
| Hover | `var(--vscode-list-hoverBackground)` | Agent card hover, tab hover |
| Focus | `var(--vscode-focusBorder)` | Focus ring on all interactive elements |

Accent reserved for: primary action buttons (Connect Workspace, Resume Agent), active toggle states. Never used for decorative or informational elements.

## Component Contracts

### Workspace Tab Bar

- Horizontal tab strip at top of panel
- Each tab: workspace name + agent count badge
- "All Workspaces" tab always first (aggregate view)
- Active tab: `--vscode-tab-activeBackground` + bottom 2px border `--vscode-focusBorder`
- Overflow: horizontal scroll with fade indicators (no wrapping)
- Tab click: switches dashboard content to that workspace

### Summary Bar

- Compact horizontal strip below tab bar
- 4 metrics: Total Agents | Running | Paused | Errors
- Each metric: codicon + numeric value + label
- Codicons: `$(pulse)` running, `$(debug-pause)` paused, `$(error)` errors, `$(organization)` total
- Background: `--vscode-sideBar-background`
- Separator: 1px `--vscode-widget-border`

### Master-Detail Split

- Left panel (40% width): scrollable agent card list
- Right panel (60% width): selected agent detail
- Divider: 1px `--vscode-widget-border` (not resizable in v1)
- Min-width left: 200px, min-width right: 300px

### Agent Card (compact, left panel)

- Layout: status dot | agent name + role | control buttons
- Status dot: 8px circle with semantic color (running/paused/stopped/error)
- Agent name: heading style (13px semibold)
- Role/current task: label style (11px normal), single-line truncated
- Control buttons: inline, right-aligned
  - Running → Pause button `$(debug-pause)` + Stop button `$(debug-stop)`
  - Paused → Resume button `$(debug-continue)` + Stop button `$(debug-stop)`
  - Stopped → no buttons (dimmed card)
- Selected card: `--vscode-list-activeSelectionBackground`
- Hover: `--vscode-list-hoverBackground`

### Agent Detail Panel (right panel)

- Header: agent name + status badge + control buttons (larger)
- Sections (vertical stack):
  1. **Info grid**: Role, Model, Session ID, PID, Workspace — 2-column key-value
  2. **Token usage**: bar showing input/output tokens with numeric labels
  3. **Recent actions**: scrollable list of last 10 tool uses (tool name, timestamp, success/fail icon)
  4. **Config excerpt**: collapsed `<details>` showing agent config JSON
- Empty state (no agent selected): centered message "Select an agent to view details"

### Toast Notifications

- Use `vscode.window.showErrorMessage()` for agent errors (D-05 StopFailure, PostToolUseFailure)
- Use `vscode.window.showInformationMessage()` for session start/end
- Status bar badge updates for running count via StatusBarManager (Phase 1)

## Accessibility

- All interactive elements must be keyboard-navigable (Tab order: tabs → summary → agent list → detail panel)
- Agent cards are `<button>` elements with `role="option"` in an `aria-listbox`
- Control buttons have `aria-label`: "Pause agent {name}", "Resume agent {name}", "Stop agent {name}"
- Status dots have `aria-label`: "{agent name} is {running|paused|stopped}"
- Color states always paired with icon or text label (not color-only)
- Focus visible outlines on all interactive elements: 1px `--vscode-focusBorder`
- High contrast theme: all VSCode variables automatically adjust
