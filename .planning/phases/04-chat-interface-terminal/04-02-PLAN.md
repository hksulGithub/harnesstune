# Plan 02: Terminal Manager + Extension Wiring

## Goal

Wire the `ClaudeCodeTerminal` into the extension: create a `TerminalManager` that maps workspace IDs to terminal instances, register the `harnesstune.openTerminal` command, integrate terminal stream-JSON events into the existing event pipeline (so dashboard and schematic stay in sync), and add workspace-level configuration for `--dangerously-skip-permissions`.

## Requirements Covered

- **CHAT-01** (complete): Terminal created per workspace via `window.createTerminal({ pty })` in the native VSCode terminal area
- **CHAT-02** (complete): Terminal routes to Claude Code backend with workspace-specific configuration
- **CHAT-03**: Terminal panel retains context when hidden -- the native VSCode terminal area retains pseudoterminal state by default (the child process stays alive, `onDidWrite` buffer is preserved by VS Code's terminal renderer). Note: `retainContextWhenHidden` is a WebviewPanel concept -- for native terminals, the equivalent behavior is automatic because the Pseudoterminal instance lives in the extension host, not in a webview.
- **CHAT-04** (complete): Full loop -- user types, input goes to Claude Code stdin, response streams back and renders in terminal

## Acceptance Criteria

- [ ] `harnesstune.openTerminal` command registered in `package.json` and `extension.ts`
- [ ] Command prompts user to select a workspace (QuickPick) if no workspaceId provided
- [ ] Terminal creates with name `HarnessTune: {workspaceName}` in the native terminal area
- [ ] Only one terminal per workspace -- opening again shows/focuses the existing terminal
- [ ] Terminal dispose cleans up the TerminalManager mapping
- [ ] Stream-JSON events from terminal flow into eventStore, controlManager, notificationService, dashboard, and schematic (same pipeline as hook events)
- [ ] `harnesstune.dangerouslySkipPermissions` workspace-level configuration available
- [ ] `npm run build` passes with no errors
- [ ] Human verification: open terminal for a workspace, start a session, send a message, see a response

#### Actions

1. **Create `src/terminal/TerminalManager.ts`**:
   - Imports: `vscode`, `ClaudeCodeTerminal`, `AgentEvent` type.
   - Constructor takes: `onEvent: (event: AgentEvent) => void` callback for pipeline integration.
   - Private state: `terminals: Map<string, { terminal: vscode.Terminal, pty: ClaudeCodeTerminal }>`.
   - **`openTerminal(workspaceId, workspaceName, workspaceRootPath, options?)`:**
     - If terminal already exists for workspaceId AND terminal is still open (check via `terminal.exitStatus === undefined`): `terminal.show()` and return.
     - If terminal exists but was closed (exitStatus defined): remove from map, dispose pty.
     - Create new `ClaudeCodeTerminal(workspaceId, workspaceName, workspaceRootPath, { dangerouslySkipPermissions: options?.dangerouslySkipPermissions, onEvent: this.onEvent })`.
     - Create `vscode.window.createTerminal({ name: 'HarnessTune: ' + workspaceName, pty })`.
     - Store in map. Call `terminal.show()`.
     - Listen for terminal close: `vscode.window.onDidCloseTerminal` -- if the closed terminal matches, remove from map and dispose pty.
   - **`getTerminal(workspaceId)`:** returns the terminal entry or undefined.
   - **`disposeAll()`:** SIGTERM all child processes, dispose all terminals, clear map.
   - Implements `vscode.Disposable` with `dispose()` calling `disposeAll()`.

   ```typescript
   // ── Phase 4: Terminal Manager ──────────────────────────────────────────────
   const terminalManager = new TerminalManager((event: AgentEvent) => {
     // Feed terminal stream-JSON events into the same pipeline as hook events
     seenSessionIds.add(event.sessionId);

     // 1. Persist
     eventStore.insertEvent(event);

     // 2. Session lifecycle
     if (!controlManager.getSession(event.sessionId)) {
       if (event.eventType !== 'SessionEnd' && event.eventType !== 'Stop') {
         controlManager.registerSession(event.sessionId, event.workspaceId, event.model);
       }
     }
     if (event.eventType === 'SessionEnd' || event.eventType === 'Stop') {
       controlManager.unregisterSession(event.sessionId);
     }

     // 3. Notifications
     notificationService.handleEvent(event);

     // 4. Push to dashboard
     if (DashboardPanel.currentPanel) {
       DashboardPanel.currentPanel.postMessage({
         type: 'dashboard:agentEvents',
         events: [event],
       });
     }

     // 5. Push to schematic
     if (SchematicPanel.currentPanel) {
       const allHierarchyEvents: AgentEvent[] = [];
       for (const ws of registry.getAll()) {
         allHierarchyEvents.push(...eventStore.getHierarchyEvents(ws.id));
       }
       const topology = buildTopology(allHierarchyEvents, undefined, seenSessionIds);
       SchematicPanel.currentPanel.postMessage({
         type: 'schematic:topologyUpdate',
         state: topology,
       });
     }
   });
   context.subscriptions.push(terminalManager);
   ```

   - Register the openTerminal command:

   ```typescript
   const openTerminalCmd = vscode.commands.registerCommand(
     'harnesstune.openTerminal',
     async (workspaceId?: string) => {
       let ws: WorkspaceRecord | undefined;

       if (workspaceId) {
         ws = registry.getById(workspaceId);
       } else {
         // Prompt user to pick a workspace
         const workspaces = registry.getAll();
         if (workspaces.length === 0) {
           vscode.window.showInformationMessage('HarnessTune: No workspaces connected. Connect a workspace first.');
           return;
         }
         if (workspaces.length === 1) {
           ws = workspaces[0];
         } else {
           const items = workspaces.map(w => ({
             label: w.name,
             description: w.rootPath,
             id: w.id,
           }));
           const selected = await vscode.window.showQuickPick(items, {
             placeHolder: 'Select workspace to open terminal for',
           });
           if (!selected) return;
           ws = registry.getById(selected.id);
         }
       }

       if (!ws) {
         vscode.window.showWarningMessage('HarnessTune: Workspace not found');
         return;
       }

       const config = vscode.workspace.getConfiguration('harnesstune');
       const skipPermissions = config.get<boolean>('dangerouslySkipPermissions', false);

       terminalManager.openTerminal(ws.id, ws.name, ws.rootPath, {
         dangerouslySkipPermissions: skipPermissions,
       });
     }
   );
   context.subscriptions.push(openTerminalCmd);
   ```
