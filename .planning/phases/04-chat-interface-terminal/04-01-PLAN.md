# Plan 01: Pseudoterminal + Stream-JSON Parser + Output Formatter

## Goal

Build the self-contained `ClaudeCodeTerminal` class that implements VSCode's `Pseudoterminal` interface, spawns `claude --output-format stream-json` as a child process, parses the newline-delimited JSON output, and renders formatted text into the terminal.

## Requirements Covered

- **CHAT-01** (partial): Pseudoterminal class implementing the VSCode native Pseudoterminal API
- **CHAT-02** (partial): Terminal spawns Claude Code as child process with stream-JSON output format
- **CHAT-04** (partial): User input written to stdin, Claude responses parsed and rendered to terminal

## Acceptance Criteria

- [ ] `ClaudeCodeTerminal` implements `vscode.Pseudoterminal` with `open`, `close`, `handleInput`, `onDidWrite`, `onDidClose`
- [ ] `open()` writes a "Press Enter to start a Claude Code session..." prompt; does NOT auto-spawn
- [ ] Pressing Enter spawns `claude --output-format stream-json` via `child_process.spawn()`
- [ ] `handleInput()` buffers a line of user input, echoes typed characters, and on Enter writes the complete line to the child process stdin
- [ ] `StreamJsonParser` buffers partial lines from stdout chunks and emits complete parsed JSON events
- [ ] `OutputFormatter` renders assistant text with basic ANSI formatting (bold headers), tool use as compact `[ToolName] summary` lines, errors in red (`\x1b[31m`), and optional usage summary
- [ ] On child process exit: writes session-end message to terminal, fires `onDidClose`
- [ ] SIGTERM sent to child process on `close()` (panel dispose)
- [ ] TypeScript compiles with no errors (`npm run build`)

## Files

### Create

- `src/terminal/types.ts` -- Stream-JSON event type definitions (discriminated union by `type` field)

## Tasks

### Task 1: Stream-JSON types, parser, and output formatter

**Commit message:** `feat(chat): add stream-JSON types, parser, and output formatter`

#### Actions

1. **Create `src/terminal/types.ts`** with a discriminated union for Claude Code stream-JSON events:
   - `StreamJsonAssistantEvent`: `{ type: 'assistant', message: { role: 'assistant', content: ContentBlock[] }, ... }` where `ContentBlock` is `{ type: 'text', text: string } | { type: 'tool_use', id: string, name: string, input: unknown }`
   - `StreamJsonToolUseEvent`: `{ type: 'tool_use', name: string, input: unknown }`
   - `StreamJsonToolResultEvent`: `{ type: 'tool_result', tool_use_id: string, content: string, is_error?: boolean }`
   - `StreamJsonUsageEvent`: `{ type: 'result', duration_ms: number, duration_api_ms: number, num_turns: number, result: string, session_id: string, total_cost_usd: number, usage: { input_tokens: number, output_tokens: number, cache_read_input_tokens?: number, cache_creation_input_tokens?: number } }`
   - `StreamJsonSystemEvent`: `{ type: 'system', message: string, session_id?: string }`
   - `StreamJsonErrorEvent`: `{ type: 'error', error: { message: string, type: string } }`
   - Union type: `StreamJsonEvent = StreamJsonAssistantEvent | StreamJsonToolUseEvent | StreamJsonToolResultEvent | StreamJsonUsageEvent | StreamJsonSystemEvent | StreamJsonErrorEvent`
   - Also export `TerminalSessionState = 'idle' | 'starting' | 'active' | 'ended'`

2. **Create `src/terminal/StreamJsonParser.ts`**:
   - Class with a `private buffer: string = ''`
   - Method `feed(chunk: string): StreamJsonEvent[]` -- appends chunk to buffer, splits on `\n`, attempts `JSON.parse()` on each complete line. Returns array of successfully parsed events. Retains incomplete last line in buffer.
   - Silently skip lines that fail `JSON.parse()` (Claude may emit non-JSON startup text).
   - Method `reset()` to clear the buffer.

3. **Create `src/terminal/OutputFormatter.ts`**:
   - Static class or pure functions -- no state needed.
   - `format(event: StreamJsonEvent): string` -- dispatches by event type:
     - `assistant`: Extract text content blocks. Apply bold ANSI (`\x1b[1m`) to lines starting with `#`. Replace `\n` with `\r\n` for terminal line endings. Return the formatted text.
     - `tool_use`: Return `\x1b[36m[${name}]\x1b[0m ${summarizeInput(input)}\r\n` (cyan tool name). `summarizeInput`: if input has `file_path` or `path`, show that; if `command`, show first 60 chars; otherwise show `JSON.stringify(input).slice(0, 80)`.
     - `tool_result`: If `is_error`, format in red. Otherwise skip (tool results are verbose -- the next assistant message will reference them).
     - `result` (usage): Format as dim text: `\x1b[2m--- ${num_turns} turns | ${total_cost_usd.toFixed(4)} USD | ${input_tokens + output_tokens} tokens ---\x1b[0m\r\n`
     - `system`: Format as dim italic: `\x1b[2;3m${message}\x1b[0m\r\n`
     - `error`: Format in bold red: `\x1b[1;31mError: ${error.message}\x1b[0m\r\n`
   - `formatPrompt(): string` -- returns the "start session" prompt text with ANSI styling.
   - `formatInputPrefix(): string` -- returns `\x1b[1;32m> \x1b[0m` (bold green prompt).
   - `formatSessionEnd(reason: string): string` -- returns styled session-end message.

4. **Create `src/terminal/index.ts`** -- barrel exports for `ClaudeCodeTerminal`, `StreamJsonParser`, `OutputFormatter`, and all types.

### Task 2: ClaudeCodeTerminal pseudoterminal class

**Commit message:** `feat(chat): implement ClaudeCodeTerminal pseudoterminal`

#### Actions

1. **Create `src/terminal/ClaudeCodeTerminal.ts`**:
   - Imports: `vscode`, `child_process`, `StreamJsonParser`, `OutputFormatter`, types.
   - Constructor takes: `workspaceId: string`, `workspaceName: string`, `workspaceRootPath: string`, `options?: { dangerouslySkipPermissions?: boolean, onEvent?: (event: AgentEvent) => void }`
   - Implements `vscode.Pseudoterminal`:
     - `onDidWrite: Event<string>` -- fires formatted text to the terminal
     - `onDidClose?: Event<number | void>` -- fires when session ends
     - `handleInput(data: string): void` -- processes keyboard input
     - `open(initialDimensions?: vscode.TerminalDimensions): void` -- called when terminal is shown
     - `close(): void` -- called when terminal is disposed

   - **Private state:**
     - `process: ChildProcess | null`
     - `parser: StreamJsonParser`
     - `state: TerminalSessionState` (starts 'idle')
     - `inputBuffer: string` (for line editing)
     - `_onDidWrite: EventEmitter<string>`
     - `_onDidClose: EventEmitter<number | void>`

   - **`open()` implementation:**
     - Write welcome banner: `OutputFormatter.formatPrompt()` which shows "HarnessTune Terminal - {workspaceName}" and "Press Enter to start a Claude Code session..."
     - Write input prefix: `OutputFormatter.formatInputPrefix()`
     - Set state to 'idle'

   - **`handleInput(data)` implementation:**
     - If `data === '\r'` (Enter key):
       - If state is 'idle': call `startSession()`
       - If state is 'active' and `inputBuffer.trim()` is non-empty: write `inputBuffer + '\n'` to child process stdin, echo `\r\n` to terminal, clear inputBuffer, show a "thinking..." indicator
       - If state is 'active' and inputBuffer is empty: just echo `\r\n`
     - If `data === '\x7f'` (Backspace): remove last char from inputBuffer, write `\x1b[D \x1b[D` (move back, overwrite, move back)
     - If `data === '\x03'` (Ctrl+C): if process running, send SIGINT to child process
     - Otherwise: append to inputBuffer, echo data to terminal via `_onDidWrite.fire(data)`

   - **`startSession()` implementation:**
     - Set state to 'starting'
     - Write "Starting Claude Code session...\r\n" to terminal
     - Build args: `['--output-format', 'stream-json']`. If `options.dangerouslySkipPermissions`, add `'--dangerously-skip-permissions'`.
     - Spawn: `child_process.spawn('claude', args, { cwd: workspaceRootPath, stdio: ['pipe', 'pipe', 'pipe'], env: { ...process.env } })`
     - Set state to 'active'
     - Wire `process.stdout.on('data', (chunk) => { ... })`: feed chunk.toString() to parser.feed(), for each parsed event call `OutputFormatter.format(event)` and fire `_onDidWrite`, also call `options.onEvent?.(normalizeStreamEvent(event))` for pipeline integration
     - Wire `process.stderr.on('data', (chunk) => { ... })`: write chunk in red ANSI to terminal
     - Wire `process.on('close', (code) => { ... })`: write session-end message, set state to 'ended', show "Press Enter to start a new session..." prompt
     - Wire `process.on('error', (err) => { ... })`: write error in red, set state to 'ended'
     - Store PID for AgentControlManager integration

   - **`close()` implementation:**
     - If process is running: send SIGTERM, then after 3s send SIGKILL if still alive
     - Fire `_onDidClose`
     - Clean up parser with `reset()`

   - **`normalizeStreamEvent(event: StreamJsonEvent): AgentEvent`** (private helper):
     - Reuse the same field mapping pattern from `ClaudeCodeHookAdapter.normalizeEvent()` but adapted for stream-JSON fields instead of hook POST fields.
     - Map `assistant` events to eventType 'SessionStart' (first) or no-op (subsequent text).
     - Map `tool_use` events to eventType 'PreToolUse' with toolName and toolInput.
     - Map `tool_result` events to eventType 'PostToolUse' or 'PostToolUseFailure' (if is_error).
     - Map `result` events to eventType 'SessionEnd' with tokenUsage.
     - Map `error` events to eventType 'StopFailure'.
     - Include `workspaceId`, generate `sessionId` from the stream-JSON session_id field (captured from `system` or `result` events), set `agentId` same as `sessionId`.

   - **`getProcessPid(): number | undefined`** -- returns `this.process?.pid` for AgentControlManager.

   - **`dispose()` method:** calls `close()`, disposes emitters.

2. **Update `src/terminal/index.ts`** to export `ClaudeCodeTerminal`.

3. **Verify:** Run `npm run build` -- all files must compile with no TypeScript errors.
