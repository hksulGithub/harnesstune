<action>
Create `packages/harnesstune-collector/src/plugins/openclaw/reader.ts` with two exported functions:

1. `listAgentDirs(agentsRoot: string): string[]`
   - Reads `agentsRoot` directory with `readdirSync`
   - Filters to entries where `statSync(join(agentsRoot, entry)).isDirectory()` is true
   - Wraps in try/catch, returns `[]` on error
   - Returns array of directory names (not full paths)

2. `scanJsonlFiles(agentsRoot: string, since: Date): Map<string, OpenClawEvent[]>`
   - Returns a `Map<string, OpenClawEvent[]>` keyed by agent directory name
   - Iterates agent subdirectories via `listAgentDirs(agentsRoot)`
   - For each agent dir, looks for a `sessions/` subdirectory: `join(agentsRoot, agentDir, 'sessions')`
   - Lists all `*.jsonl` files in the sessions dir
   - For each JSONL file:
     - Check `statSync(filePath).mtime.getTime()` against `since.getTime()` — skip files with mtime < since
     - Staleness guard: skip files with mtime within 30 seconds of `Date.now()` (still running)
     - Read file with `readFileSync(filePath, 'utf-8')`
     - Split on `'\n'`, filter out blank lines
     - Parse each line with `JSON.parse` in its own try/catch — on error, `console.warn` and skip
     - Cast parsed object to `OpenClawEvent`, set `agentId` to the directory name if not present
     - Filter events: only include events whose `ts` timestamp (`new Date(event.ts).getTime()`) is >= `since.getTime()`
   - Accumulates all events per agent into the Map
   - Wraps outer loops in try/catch, returns empty Map on catastrophic error

Imports:
```ts
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';
import type { OpenClawEvent } from './types.js';
```

No third-party dependencies. All I/O uses `node:fs` sync methods only.
</action>

   ```ts
   export const DEFAULT_SESSION_GAP_MS = 5 * 60 * 1000; // 5 minutes
   ```

2. Exported function:
   ```ts
   export function segmentEvents(
     events: OpenClawEvent[],
     gapMs: number = DEFAULT_SESSION_GAP_MS,
   ): OpenClawSession[]
   ```

Implementation:
- Return `[]` if `events.length === 0`
- Sort events by `ts` using `new Date(a.ts).getTime() - new Date(b.ts).getTime()`
- Extract `agentId` from the first event's `agentId` field
- Initialize a current session buffer: `let currentEvents: OpenClawEvent[] = [events[0]]`
- Iterate remaining events (index 1 to end):
  - If `new Date(events[i].ts).getTime() - new Date(events[i-1].ts).getTime() > gapMs`:
    - Flush: push an `OpenClawSession` with `agentId`, `startedAt: currentEvents[0].ts`, `finishedAt: currentEvents[currentEvents.length - 1].ts`, `events: currentEvents`
    - Reset: `currentEvents = [events[i]]`
  - Else: `currentEvents.push(events[i])`
- After loop: flush remaining buffer as final session
- Return array of `OpenClawSession`

Imports:
```ts
import type { OpenClawEvent, OpenClawSession } from './types.js';
```

No I/O, no side effects — pure function only.
</action>

<threat_model>

### T1: Path Traversal via Agent Directory Names (Severity: MEDIUM)
**Threat:** A malicious or corrupted `~/.openclaw/agents/` entry could contain `../` segments, causing the reader to escape the agents root.
**Mitigation:** `listAgentDirs` returns directory names only (not paths). `scanJsonlFiles` joins names via `join(agentsRoot, agentDir)` and the `statSync().isDirectory()` check prevents symlink-to-file traversal. Additionally, the reader only reads `.jsonl` files, limiting what can be accessed.

### T2: Malformed JSONL Causes Crash (Severity: LOW)
**Threat:** Corrupted or truncated JSONL lines crash the collector process.
**Mitigation:** Every `JSON.parse` call is wrapped in its own try/catch. Malformed lines are logged with `console.warn` and skipped. The reader never throws — returns empty collections on error.

### T3: Large JSONL Files Cause OOM (Severity: MEDIUM)
**Threat:** An agent with very long-running sessions could produce multi-gigabyte JSONL files, causing `readFileSync` to exhaust memory.
**Mitigation:** The mtime guard skips files older than `since`, limiting the number of files read. The staleness guard skips actively-written files. For v1, this is acceptable; streaming line-by-line reads can be added if needed. The daemon's 60s poll cycle with cursor advancement means files are typically small.

</threat_model>
