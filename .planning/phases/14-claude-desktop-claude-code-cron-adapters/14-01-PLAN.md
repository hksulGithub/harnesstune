## Threat Model

| # | Threat | Severity | Mitigation |
|---|--------|----------|------------|
| T1 | JSON.parse of scheduled-tasks.json during concurrent Claude Desktop write → partial JSON → crash | Medium | reader.ts wraps all JSON.parse in try/catch; returns empty array on parse error |
| T2 | Session file read race — file written by Claude Desktop while collector reads | Medium | readSessionFile returns null on parse error; collectRuns skips null entries |
| T3 | Path traversal via crafted scheduledTaskId in session file | Low | scheduledTaskId is only used as a string comparison key against known task IDs; never used in path construction |
| T4 | Unbounded memory from scanning thousands of session files | Low | scanSessions filters by mtime > since before reading file content; only recent files are parsed |

No high-severity threats. All mitigated by defensive coding in reader.ts.
</threat_model>

## Goal

Create the Claude Desktop plugin's data layer: platform-specific TypeScript interfaces for `scheduled-tasks.json` and session file JSON, pure mapper functions that transform these to `AgentIdentity` and `RunReport`, and file I/O utilities that read and filter Claude Desktop data from disk.

## must_haves

- `ScheduledTask` interface with fields: `id`, `cronExpression`, `enabled`, `lastRunAt`, `lastScheduledFor`, `createdAt`, `filePath`, `model`, `approvedPermissions`, `disableJitter`
- `SessionFile` interface with fields: `sessionId`, `scheduledTaskId?`, `sessionType?`, `createdAt` (epoch ms), `lastActivityAt` (epoch ms), `error?`, `isArchived`, `title`, `model`
- `mapScheduledTask()` returns `AgentIdentity` with `platform: 'claude-desktop'`, `status` derived from `enabled` field
- `mapSessionToRunReport()` returns `RunReport` with `status: 'failure'` when `error` field present, `durationMs` computed from epoch ms timestamps
- `readScheduledTasks()` wraps `JSON.parse` in try/catch, returns `[]` on error
- `scanSessions()` filters by `scheduledTaskId` presence and `since` date
- `getScheduledTasksMtime()` returns `Date` from `statSync().mtime`

```typescript
import type { RunReport } from '@harnesstune/shared';
import type { AgentIdentity } from '../../types.js';
import type { ScheduledTask, SessionFile } from './types.js';

export function mapScheduledTask(task: ScheduledTask): AgentIdentity {
  return {
    agentId: task.id,
    name: task.id,
    platform: 'claude-desktop',
    schedule: task.cronExpression,
    lastRunAt: task.lastRunAt ?? null,
    status: task.enabled ? 'active' : 'paused',
  };
}

export function mapSessionToRunReport(session: SessionFile, taskId: string): RunReport {
  return {
    agentId: taskId,
    startedAt: new Date(session.createdAt).toISOString(),
    finishedAt: new Date(session.lastActivityAt).toISOString(),
    status: session.error ? 'failure' : 'success',
    durationMs: session.lastActivityAt - session.createdAt,
    errorSummary: session.error,
    logExcerpt: session.error ? `[${session.model}] ${session.error}` : undefined,
  };
}
```

Both functions are pure (no I/O, no side effects). `tokenUsage` and `costCents` are omitted (Claude Desktop does not expose these locally).

```typescript
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join } from 'node:path';
import type { ScheduledTask, ScheduledTasksFile, SessionFile } from './types.js';

const SCHEDULED_TASKS_FILE = 'scheduled-tasks.json';

/**
 * Get mtime of scheduled-tasks.json for the mtime guard (D-03).
 * Returns epoch 0 if file does not exist or stat fails.
 */
export function getScheduledTasksMtime(sessionsDir: string): Date {
  try {
    return statSync(join(sessionsDir, SCHEDULED_TASKS_FILE)).mtime;
  } catch {
    return new Date(0);
  }
}

/**
 * Read and parse scheduled-tasks.json. Returns [] on any error
 * (file missing, partial JSON from concurrent write — risk 5.1).
 */
export function readScheduledTasks(sessionsDir: string): ScheduledTask[] {
  try {
    const raw = readFileSync(join(sessionsDir, SCHEDULED_TASKS_FILE), 'utf-8');
    const parsed = JSON.parse(raw) as ScheduledTasksFile;
    return parsed.scheduledTasks ?? [];
  } catch {
    return [];
  }
}

/**
 * Read a single session file. Returns null on any parse error (risk 5.2).
 */
export function readSessionFile(filePath: string): SessionFile | null {
  try {
    const raw = readFileSync(filePath, 'utf-8');
    return JSON.parse(raw) as SessionFile;
  } catch {
    return null;
  }
}

/**
 * Scan session directory for local_*.json files modified since `since`.
 * Filters to only scheduled sessions (scheduledTaskId present).
 * Applies staleness guard: excludes sessions with lastActivityAt within
 * 30 seconds of now (likely still running — risk 5.2).
 */
export function scanSessions(sessionsDir: string, since: Date): SessionFile[] {
  const sinceMs = since.getTime();
  const nowMs = Date.now();
  const STALENESS_GUARD_MS = 30_000;
  const results: SessionFile[] = [];

  let entries: string[];
  try {
    entries = readdirSync(sessionsDir);
  } catch {
    return [];
  }

  for (const entry of entries) {
    // Only match local_*.json files (not directories like local_*/)
    if (!entry.startsWith('local_') || !entry.endsWith('.json')) continue;

    const filePath = join(sessionsDir, entry);

    // Quick mtime filter: skip files older than `since`
    try {
      const mtime = statSync(filePath).mtime.getTime();
      if (mtime < sinceMs) continue;
    } catch {
      continue;
    }

    const session = readSessionFile(filePath);
    if (!session) continue;

    // D-02: only scheduled sessions (ignore ad-hoc/interactive)
    if (!session.scheduledTaskId) continue;

    // Staleness guard: skip sessions that appear still running
    if (session.lastActivityAt > nowMs - STALENESS_GUARD_MS) continue;

    // Time filter on session data (not just mtime)
    if (session.lastActivityAt < sinceMs) continue;

    results.push(session);
  }

  return results;
}
```

Key design decisions reflected:
- `readScheduledTasks()` wraps `JSON.parse` in try/catch for race condition mitigation (risk 5.1)
- `readSessionFile()` returns `null` on error for graceful partial failure
- `scanSessions()` applies three filters: mtime pre-filter, `scheduledTaskId` presence (D-02), and 30s staleness guard (risk 5.2)
- No file watchers — polling only (D-10)
