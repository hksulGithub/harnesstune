## Threat Model

| # | Threat | Severity | Mitigation |
|---|--------|----------|------------|
| T1 | Shell injection via crafted `--name` value in wrapper script | Medium | Wrapper uses `"$@"` pass-through; `--name` value is written to JSON via printf %s with proper quoting, never interpolated into shell commands |
| T2 | crontab -l output contains unexpected binary/encoding | Low | parseCrontab treats non-UTF8 lines gracefully; skips unparseable lines with console.warn |
| T3 | Run file read race — collector reads while wrapper writes | Medium | Wrapper uses atomic rename pattern: write to `.json.tmp`, then `mv` to `.json`; collector ignores `.json.tmp` files |
| T4 | Symlink attack on ~/.harnesstune/cron-runs/ | Low | Directory created with mkdirSync by collector setup; wrapper only writes files, never follows symlinks for reads |
| T5 | Wrapper script overwritten by attacker to capture agent tokens | Medium | Wrapper script has no access to tokens — all relay communication is in the collector daemon. Wrapper only writes local JSON files. chmod 755 (world-executable but only owner-writable). |

No high-severity threats. T5 is explicitly mitigated by the D-05 architecture decision (wrapper has no network access, no tokens).
</threat_model>

## Goal

Create the Claude Code cron plugin's data layer: TypeScript interfaces for crontab entries and run files, mapper functions to `AgentIdentity` and `RunReport`, a crontab parser, and a bash wrapper script generator.

## must_haves

- `CronRunFile` interface with fields: `agentName`, `command`, `exitCode`, `startedAt`, `finishedAt`, `durationMs`, `outputTail`
- `CrontabEntry` interface with fields: `schedule`, `agentName`, `rawLine`
- `mapCrontabEntry()` returns `AgentIdentity` with `platform: 'claude-code'`
- `mapCronRunFile()` returns `RunReport` with `status: 'failure'` when `exitCode !== 0`
- `parseCrontab()` filters lines containing `harnesstune-wrap`, extracts `--name` value and cron schedule
- `readCrontab()` calls `execFileAsync('crontab', ['-l'])`, treats exit code 1 as empty
- `generateWrapperScript()` returns bash string with `--name` parsing, atomic JSON write, exit code preservation
- Wrapper script writes to `$HOME/.harnesstune/cron-runs/<timestamp>-<name>.json.tmp` then renames to `.json`

export function mapCrontabEntry(entry: CrontabEntry): AgentIdentity {

    agentId: entry.agentName,
    name: entry.agentName,
    platform: 'claude-code',
    schedule: entry.schedule,
    lastRunAt: null,
    status: 'active',
  };

export function mapCronRunFile(file: CronRunFile): RunReport {
  const isFailed = file.exitCode !== 0;
  return {
    agentId: file.agentName,
    startedAt: file.startedAt,
    finishedAt: file.finishedAt,
    status: isFailed ? 'failure' : 'success',
    durationMs: file.durationMs,
    logExcerpt: file.outputTail,
    errorSummary: isFailed
      ? `Exit code ${file.exitCode}: ${file.outputTail.split('\n').slice(-3).join(' | ')}`
      : undefined,
  };
}

**1. `crontab.ts`** — Crontab parser + reader:

```typescript
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import type { CrontabEntry } from './types.js';

const execFileAsync = promisify(execFile);

/** Regex to extract --name value (quoted or unquoted) */
const NAME_REGEX = /--name\s+['"]?([^'"]+?)['"]?(?:\s|$)/;

/**
 * Parse raw crontab output into CrontabEntry[] filtered for harnesstune-wrap lines.
 * Pure function — no I/O.
 */
export function parseCrontab(output: string): CrontabEntry[] {
  const entries: CrontabEntry[] = [];

  for (const line of output.split('\n')) {
    const trimmed = line.trim();

    // Skip blank lines, comments, env var assignments
    if (!trimmed || trimmed.startsWith('#') || /^\s*\w+=/.test(trimmed)) continue;

    // Only process lines containing harnesstune-wrap
    if (!trimmed.includes('harnesstune-wrap')) continue;

    // Extract --name value
    const nameMatch = trimmed.match(NAME_REGEX);
    if (!nameMatch) {
      console.warn(`harnesstune-wrap entry missing --name flag, skipping: ${trimmed}`);
      continue;
    }

    const agentName = nameMatch[1];

    // Extract schedule
    let schedule: string;
    if (trimmed.startsWith('@')) {
      // Special schedule like @reboot, @daily, etc.
      schedule = trimmed.split(/\s+/)[0];
    } else {
      // Standard 5-field cron expression
      const fields = trimmed.split(/\s+/);
      schedule = fields.slice(0, 5).join(' ');
    }

    entries.push({ schedule, agentName, rawLine: trimmed });
  }

  return entries;
}

/**
 * Read the current user's crontab. Returns [] if no crontab exists
 * (exit code 1 is treated as empty, not an error — per research 3.2).
 */
export async function readCrontab(): Promise<CrontabEntry[]> {
  try {
    const { stdout } = await execFileAsync('crontab', ['-l']);
    return parseCrontab(stdout);
  } catch {
    // Exit code 1 = "no crontab for user" or cron disabled — not an error
    return [];
  }
}
```

**2. `wrapper.ts`** — Wrapper script generator (pure function):

```typescript
/**
 * Generate the harnesstune-wrap bash script.
 * Pure function — returns the script as a string.
 * The script captures exit code, duration, and output tail for cron-based
 * Claude Code invocations. Writes a JSON run file to ~/.harnesstune/cron-runs/
 * using atomic temp-file-then-rename (risk 5.7 mitigation).
 */
export function generateWrapperScript(): string {
  return `#!/usr/bin/env bash
# harnesstune-wrap — capture exit code, duration, output tail for Claude Code cron jobs
# Usage: harnesstune-wrap --name <agent-name> <command> [args...]
# Written by harnesstune-collector setup. Do not edit manually.

set -uo pipefail

RUNS_DIR="\$HOME/.harnesstune/cron-runs"
OUTPUT_TAIL_LINES=50

# --- Parse --name flag ---
if [ "\$#" -lt 3 ] || [ "\$1" != "--name" ]; then
  echo "Usage: harnesstune-wrap --name <agent-name> <command> [args...]" >&2
  exit 2
fi

AGENT_NAME="\$2"
shift 2

# --- Ensure runs directory exists ---
mkdir -p "\$RUNS_DIR"

# --- Record start time ---
STARTED_AT=\$(date -u +"%Y-%m-%dT%H:%M:%S.000Z")
START_EPOCH=\$(date +%s)

# --- Run the wrapped command, capture output ---
TMPOUT=\$(mktemp)
"\$@" > "\$TMPOUT" 2>&1
EXIT_CODE=\$?

# --- Record end time ---
FINISHED_AT=\$(date -u +"%Y-%m-%dT%H:%M:%S.000Z")
END_EPOCH=\$(date +%s)
DURATION_MS=$(( (END_EPOCH - START_EPOCH) * 1000 ))

# --- Capture last N lines of output ---
OUTPUT_TAIL=\$(tail -n "\$OUTPUT_TAIL_LINES" "\$TMPOUT" | sed 's/\\\\/\\\\\\\\/g; s/"/\\\\"/g; s/\\t/\\\\t/g')
rm -f "\$TMPOUT"

# --- Build JSON (no jq dependency — use printf) ---
TIMESTAMP=\$(date +%s%N | cut -c1-13)
RUN_FILE="\$RUNS_DIR/\${TIMESTAMP}-\${AGENT_NAME}.json"
TMP_FILE="\${RUN_FILE}.tmp"

printf '{
  "agentName": "%s",
  "command": "%s",
  "exitCode": %d,
  "startedAt": "%s",
  "finishedAt": "%s",
  "durationMs": %d,
  "outputTail": "%s"
}\\n' "\$AGENT_NAME" "\$(echo "\$*" | sed 's/"/\\\\"/g')" "\$EXIT_CODE" "\$STARTED_AT" "\$FINISHED_AT" "\$DURATION_MS" "\$OUTPUT_TAIL" > "\$TMP_FILE"

# --- Atomic rename (risk 5.7 mitigation) ---
mv "\$TMP_FILE" "\$RUN_FILE"

# --- Exit with the wrapped command's exit code ---
exit \$EXIT_CODE
`;
}
```

The wrapper script:
- Requires `--name` flag (exits with code 2 if missing, per D-09)
- Captures last 50 lines of stdout+stderr
- Writes JSON to `~/.harnesstune/cron-runs/<timestamp>-<name>.json.tmp` then renames to `.json` (atomic)
- Exits with the wrapped command's exit code (preserves cron error detection)
- Has zero network calls, zero auth tokens (D-05 architecture)
